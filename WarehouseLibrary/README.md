## Описание

Решение содержит три проекта:

- WarehouseLibrary — библиотека классов для учёта товаров на складе.
- WarehouseLibrary.Tests — модульные тесты (MSTest).
- WarehouseDemo — консольная демонстрация обработки исключений.

## Структура

WarehouseLibrary/
- Entities/Product.cs — класс-сущность «Товар»
- Interfaces/IWarehouseService.cs — интерфейс сервиса
- Services/WarehouseService.cs — реализация сервиса
- Exceptions/ — собственные исключения

WarehouseLibrary.Tests/
- WarehouseServiceTests.cs — модульные тесты

WarehouseDemo/
- Program.cs — демонстрация try-catch-finally

## Возможности библиотеки

- добавление товара
- удаление товара
- поиск товара по Id
- отгрузка товара
- получение списка всех товаров
- проверка параметров и возбуждение собственных исключений

## Сборка и запуск

Сборка решения:

    Сборка → Собрать решение (Ctrl+Shift+B)

Запуск тестов:

    Тест → Обозреватель тестов → Запустить все
